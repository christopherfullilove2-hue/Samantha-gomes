🔒 Security and Connections

This GitHub Pages version does not store API keys. Gmail, calendars, financial accounts, other AI services, and external databases are not connected. They require separate authorized integrations.

The microphone works while supported by the browser. Continuous background listening, locked-screen listening, and operation with the phone powered off are not supported.
